# Roadmap по изучению нейронных сетей с нуля

## Цель

Изучить устройство нейронных сетей "под капотом", самостоятельно реализовав все основные алгоритмы без использования NumPy и PyTorch. После этого перейти к работе с PyTorch и обучению ИИ для игры в палочки.

---

# Этап 0. Подготовка

## Цель

Освежить математическую базу.

## Необходимо изучить

* Что такое функция
* Что такое переменная
* График функции
* Степени
* Логарифмы
* Экспонента
* Производная
* Частная производная

## Результат

Уметь самостоятельно вычислить производную функции

[
f(x)=3x^2+5x+1
]

и объяснить её смысл.

---

# Этап 1. Один искусственный нейрон

## Теория

Изучить модель

[
y = w \cdot x + b
]

Понять:

* вход (Input)
* вес (Weight)
* смещение (Bias)
* выход (Output)

## Практика

Реализовать класс `Neuron`.

Без NumPy.

Только Python.

Нейрон должен:

* создавать случайные веса;
* принимать вход;
* вычислять выход.

После этого вручную менять веса и наблюдать, как меняется ответ.

## Результат

Понимание того, что нейрон — это обычная математическая функция.

---

# Этап 2. Несколько нейронов

## Теория

Изучить понятие слоя.

## Практика

Создать класс `Layer`, который содержит список объектов `Neuron`.

## Результат

Понимание того, что слой — это просто набор нейронов.

---

# Этап 3. Многослойная сеть

## Теория

Изучить прохождение данных через несколько слоёв.

## Практика

Создать класс `NeuralNetwork`, который последовательно вызывает вычисления всех слоёв.

## Результат

Понимание того, что нейросеть — это последовательность вычислений.

---

## Теория

* Sigmoid

Самостоятельно реализовать:

* relu()
* sigmoid()
* tanh()

После этого реализовать их производные.

## Результат

Понимание роли нелинейности.

# Этап 5. Функции ошибки

## Теория

Изучить:

* Mean Squared Error (MSE)
* Cross Entropy

## Практика

Реализовать обе функции самостоятельно.

## Результат

# Этап 6. Производные

## Теория

Изучить:

* производную;
* частную производную;
* правило цепочки (Chain Rule).

## Практика

* x²

# Этап 7. Градиентный спуск

## Теория

Изучить принцип минимизации функции.

## Практика

Реализовать градиентный спуск для функции

до нахождения минимума.

## Результат

# Главное правило

Не переходить к следующему этапу, пока предыдущий не получается:

* объяснить своими словами;
* реализовать без подсказок;
* воспроизвести с нуля.
