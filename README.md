# Learning AI — нейросеть на чистом Python

Учебный проект для изучения нейронных сетей изнутри: от одного нейрона и производных до многослойной сети, обратного распространения ошибки и обучения с градиентным спуском.

Основные вычисления реализованы вручную на Python, без NumPy и PyTorch: веса хранятся в списках, градиенты вычисляются явно. Matplotlib используется для графика ошибки. Отдельный эксперимент с игрой в палочки использует PyTorch.

## Что реализовано

- Нейрон с весами и смещением: `z = sum(wᵢ * xᵢ) + b`.
- Случайная инициализация весов: `uniform`, `he`, `xavier`.
- Полносвязный слой `Layer` и последовательная сеть `Network`.
- Активации ReLU, LeakyReLU, Sigmoid, Tanh и их обратный проход.
- MSE и бинарная Cross Entropy с производными по предсказанию.
- Обратное распространение ошибки через слои и обновление параметров с SGD.
- Интерактивный график ошибки во время обучения.

## Установка и запуск

Нужен Python 3.10 или новее: в коде используются аннотации типов с `|`.

```bash
git clone https://github.com/Xcx9/Learning_AI.git
cd Learning_AI
python3 -m venv .venv
source .venv/bin/activate
python -m pip install matplotlib
python "Preps for creating AI/sandbox.py"
```

Matplotlib требуется даже при `show_graph=False`, поскольку модуль визуализации импортируется вместе с `Network`.

Текущий `sandbox.py` проверяет один шаг обучения на примере `x=3`, `target=6`. При начальных `w=1`, `b=0` и скорости `0.01` результат обновления:

```text
0.06
[1.18]
```

В начале скрипт также выводит список пробных входов. `sandbox.py` служит рабочей площадкой, поэтому его содержимое меняется по мере прохождения упражнений.

## Пример: обучение функции y = 2x

Следующий код можно поместить в `sandbox.py` или отдельный файл в папке `Preps for creating AI/`, где доступны импорты модулей:

```python
import random

from Layer import Layer
from Loss import MSE
from Network import Network
from Optimizer import SGD

random.seed(42)
data = [[[x], 2 * x] for x in range(10)]

layer = Layer(1, activation=None, optimizer=SGD(lr=0.01))
net = Network([layer], loss=MSE())
net.backward(data, epochs=5000)

neuron = layer.neurons[0]
print("Вес:", neuron.weights[0], "Bias:", neuron.b)

for x in (-3, 0, 0.5, 9, 15):
    prediction = net.forward([x])[0]
    print(f"x={x}, prediction={prediction:.4f}, target={2 * x}")
```

Ожидается вес около `2` и смещение около `0`. Выходной слой оставлен без активации, чтобы предсказание могло принимать любые вещественные значения.

## Пример: бинарная классификация

Для меток `0` и `1` используются Sigmoid на выходе и `CROSS_ENTROPY`:

```python
import random

from Activations import Sigmoid
from Layer import Layer
from Loss import CROSS_ENTROPY
from Network import Network
from Optimizer import SGD

random.seed(42)
data = [[[0], 0], [[1], 1]]

layer = Layer(1, activation=Sigmoid(), optimizer=SGD(lr=0.1))
net = Network([layer], loss=CROSS_ENTROPY())
net.backward(data, epochs=1000)

for x in (0, 1):
    probability = net.forward([x])[0]
    print(f"Вход {x}: вероятность класса 1 = {probability:.4f}")
```

Для этих двух обучающих примеров ожидаются вероятности примерно `0.03` и `0.98`. Это проверка механики обучения; она не оценивает качество модели на сложной задаче.

## Как устроено обучение

1. `Network.forward(x)` последовательно передаёт вход через слои и возвращает список выходов.
2. Функция ошибки получает аргументы в порядке `(target, prediction)`.
3. Её метод `derivative()` вычисляет производную по предсказанию.
4. Сеть вызывает `Layer.backward()` от последнего слоя к первому.
5. Активации и нейроны применяют правило цепочки. Оптимизатор обновляет веса и bias.

`Network.backward(data, epochs)` запускает весь цикл обучения. Одна эпоха — один проход по всем примерам; параметры обновляются после каждого примера. Скорость обучения задаётся при создании `SGD(lr=...)` и хранится внутри оптимизатора.

Число входов нейрона определяется при первом прямом проходе. Для ручной проверки можно заранее задать `neuron.weights` и `neuron.b`; длина списка весов должна совпадать с числом входов.

Для графика передайте `show_graph=True` в `Network`. Нужна среда с поддержкой графических окон.

## Ограничения текущей версии

- Цикл обучения рассчитан на один выходной нейрон и скалярную целевую метку: для ошибки используется `prediction[0]`.
- `CROSS_ENTROPY` реализует именно бинарную Cross Entropy по вероятности, а не многоклассовую функцию по логитам. Вход ограничивается диапазоном `[1e-12, 1 - 1e-12]` для защиты логарифмов и деления.
- Sigmoid пока может переполняться при больших отрицательных входах.
- Классы `Momentum` и `Adam` пока повторяют обновление SGD; соответствующие алгоритмы ещё не реализованы.
- Собственного `Tensor`, автоматического дифференцирования, сохранения моделей и обучения мини-батчами пока нет.

## Игра в палочки

В `Nim game AI/Pytorch glasses AI.py` находится отдельный прототип с PyTorch: сеть выбирает действие, получает награду и обучается на примерах из памяти.

```bash
python -m pip install torch
python "Nim game AI/Pytorch glasses AI.py"
```

При запуске скрипт сразу начинает обучение на 10 000 эпизодах. Пока цель обновления задаётся непосредственной наградой, без оценки следующего состояния; полноценный DQN ещё не реализован.
